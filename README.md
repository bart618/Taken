# Taken en notities

Persoonlijke takenlijst met notities, als installeerbare web-app (PWA).

- Taken en notities worden opgeslagen op het apparaat zelf (in de browser).
- Gebruik **Back-up downloaden** en **Back-up terugzetten** om gegevens over te zetten tussen apparaten.
- Na een wijziging aan de app: verhoog `VERSION` in `sw.js`, zodat telefoons de nieuwe versie ophalen.
